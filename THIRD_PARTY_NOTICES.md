# Third-party notices - MO2 Theme Framework

## Mod Organizer 2

The plugin runs on the Mod Organizer 2 Python plugin API (https://github.com/ModOrganizer2/modorganizer, GPL-3.0).
How MO2 loads and applies a theme and where it keeps its list colours were read from MO2 2.5.2's source
(`MO2-REFERENCE.md`).

## MO2 Default Colors

The `meta.ini` colour writer comes from **MO2 Default Colors** by the same author (ApocryphaRealm,
GPL-3.0-or-later). No third-party code.

## Mod Organizer Plugin Browser

The built-in remap table lists the colours the Mod Organizer Plugin Browser hard-codes in its widget stylesheets, so
its windows follow the active theme. No code of the Plugin Browser is used or shipped.
